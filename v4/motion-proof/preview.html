⑧ Known limitations and scope

honest record
  • ⚠
    File size — ~2.4 MB per SVG due to base64 PNG embed. Not optimised for production publish.
  • ⚠
    GitHub animation — GitHub may pause CSS animations in <img> tags. Requires real-browser test on the published profile.
  • ⚠
    Edge halos — SVG clip paths retain small lit/coloured edges from the approved source. Suitable for dark backgrounds; full matte not claimed.
  • ⚠
    Browser recording — 12-second recording attempted via browser tool. Result reported in QA report.
  • ✓
    Scope boundary — No blinking, arm gestures, breathing or torso rotation. Folded arms stay static. Conservative head-only idle rig.
  • ✓
    Appearance lock — Approved fuller build, grown beard, curly hair, silver watch, white shoes, cyan/orange accents. No regeneration or modification.
